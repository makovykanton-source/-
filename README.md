# Telegram-бот для выдачи PDF-гайда

Готовый Telegram-бот на Python (`aiogram`), который:

- показывает приветствие от **«Сыроватка и партнеры»**;
- просит подписаться на канал **@syrovatka_t**;
- проверяет подписку через `getChatMember`;
- выдает ссылку на PDF-гайд только подписанным пользователям;
- показывает контакты юриста **Татьяны Сыроватка**;
- логирует запуск и ошибки Telegram API.

## Что делает бот

### `/start`

Бот отправляет сообщение:

- представляется как **«Сыроватка и партнеры»**;
- пишет: **«Чтобы забрать гайд, подпишитесь на мой Telegram-канал»**;
- показывает кнопку **«Проверить подписку»**;
- показывает кнопку **«Контакты»**.

### Если пользователь не подписан

Бот:

- пишет **«Вы не подписаны на канал»**;
- показывает кнопку **«Подписаться»** со ссылкой на канал;
- показывает кнопку **«Проверить снова»**;
- оставляет кнопку **«Контакты»**.

### Если пользователь подписан

Бот:

- пишет **«Спасибо за подписку! Вот ваш гайд:»**;
- показывает кнопку **«Открыть PDF-гайд»**;
- добавляет контактные данные юриста.

## Переменные окружения

Используются две обязательные переменные окружения:

```env
BOT_TOKEN=replace_with_telegram_bot_token
CHANNEL_ID=@syrovatka_t
```

> `CHANNEL_ID` можно передать как `@syrovatka_t` или как числовой ID/username канала, если вы используете другой приватный/публичный канал.

## Установка и запуск

### 1. Создайте виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Подготовьте `.env`

```bash
cp .env.example .env
```

Заполните `BOT_TOKEN` и `CHANNEL_ID`.

### 4. Добавьте бота в канал

Чтобы проверка через `getChatMember` работала корректно, бот должен иметь доступ к информации об участниках канала. Обычно для этого бота добавляют в канал и выдают ему необходимые права.

### 5. Запустите бота

```bash
python -m telegram_guide_bot
```

- `telegram_guide_bot/handlers/common.py` — `/start`, проверка подписки, контакты;

- `telegram_guide_bot/keyboards.py` — inline-кнопки;
- `telegram_guide_bot/texts.py` — тексты сообщений.
